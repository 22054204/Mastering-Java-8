# Java 8 Learning Roadmap

A structured collection of Java 8 concepts, examples, and hands-on practice programs.

## Topics to Learn

### Java 8 Features

-  **1. Lambda_Expressions**
-  **2. Stream API**
-  **3. Date and Time API**
-  **4. Base64 Encoding and Decoding**
-  **5. Method References and Constructor References (`::` Operator)**
-  **6. Default Methods In Interfaces**
-  **7. Static Methods in Interfaces**
-  **8. Functional Interfaces**
    - Single Abstract Method (SAM)
    - `@FunctionalInterface` annotation
-  **9. Optional Class**
-  **10. Java I/O Improvements**
-  **11. Collection API Improvements**

## Learning Approach

- Understand the concepts and their purpose.
- Write Java programs for each feature.
- Practise examples and explore practical use cases.
- Maintain separate packages for different concepts.
- Push code regularly to this repository.

## Repository Information

**Language:** Java

**Focus:** Java 8 Features, Concepts and Practical Implementation
